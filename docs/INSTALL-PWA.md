# Instalar Synthetiq Panel

## Android / Chrome
1. Abrir `https://lamanitodelvegano.vercel.app/admin`.
2. Iniciar sesión.
3. Abrir el menú de Chrome.
4. Elegir `Instalar aplicación` o `Añadir a pantalla principal`.
5. La app abrirá `/admin` en modo standalone.

## Nota
El manifiesto también permite que Wonka Hub muestre un botón `Instalar panel` cuando el navegador emite `beforeinstallprompt`.
